Nebulus is a multi-agent AI COO built to run startup operations with shared context, approval-aware workflows, and persistent execution across teams. It combines a Next.js control layer with a FastAPI backend, task orchestration, and real-time data services so operators can delegate planning, coordination, and execution to specialized agents.
